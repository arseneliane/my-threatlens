What My ThreatLens does

My ThreatLens helps a cybersecurity analyst monitor selected technologies for relevant vulnerabilities, exploits, and public threat intelligence. It collects matching public-source findings into one temporary review workspace.

How to use the website

  1. Define your scope: on the Dashboard, choose the technologies you use, the security keywords you care about, trusted sources, and a publication date range.
  2. Save the setup: open the menu and select Save. Use Setups to create, load, duplicate, rename, search, or delete monitoring profiles.
  3. Run the scan: select Scan Now and wait for the progress indicator to finish. The scan checks only the scope saved in the active setup.
  4. Review the results: filter by severity, technology, source, CVE, or review state. Select a finding to read its evidence, record notes, complete the checklist, or ask a finding-specific question.
  5. Share the result: Export downloads the currently filtered findings as an Excel workbook. Email sends the filtered report only when the site owner has configured an SMTP mail account.

Browser workspace and saved data

Each browser has its own independent workspace. Changes on your laptop do not change your supervisor's setup in another browser or on another computer. Setup configuration is backed up in that browser so it can be restored after a temporary hosted-server restart. Clearing site data or using a private window starts a new workspace.

Findings, review notes, checklist state, and chat messages are temporary and are not saved in browser storage.

Email delivery

Email is optional and must be connected by the site owner through the Zoho Mail API or an available SMTP provider. Until then, use Export and attach the generated Excel report through an approved company channel.

Data privacy

The demonstration uses a shared login only to restrict access to the site. It has no personal user accounts or analytics. Passwords and SMTP secrets stay in server environment settings and are never stored in the browser workspace.

Sources

The application is designed for approved government, vendor, and cybersecurity news feeds. The included offline fixture collector keeps tests deterministic.

AI disclosure

The site-wide assistant and each finding-specific assistant use an open AI model through Ollama. AI-assisted summaries, relevance explanations, and chat responses may be incomplete, outdated, or incorrect. They are decision-support content, not a substitute for professional judgment. Verify every important claim against the linked primary source, vendor advisory, CVE record, and your organization's actual asset inventory before taking action.

Known limitations

Public sources can change, rate-limit, or become unavailable. This build uses deterministic fixtures by default; live collector validation requires network access.
