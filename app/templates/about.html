What it does

My ThreatLens helps a cybersecurity analyst monitor selected technologies for relevant vulnerabilities, exploits, and public threat intelligence.

How to use it

  1. Choose technologies, keywords, trusted sources, and a date range.
  2. Save the named setup and run a scan.
  3. Filter findings, open reviews, ask grounded questions, and export the current filtered set to Excel.

Data privacy

Setups, findings, notes, checklist state, and chat history are stored locally in SQLite. There are no accounts, analytics, or SMTP credentials.

Sources

The application is designed for approved government, vendor, and cybersecurity news feeds. The included offline fixture collector keeps tests deterministic.

AI disclosure

AI-assisted content may be incomplete or incorrect. Verify recommendations against the cited vendor advisory, CVE record, and your own environment before taking action. This app is still under testing and can be enhanced more.

Known limitations

Public sources can change, rate-limit, or become unavailable. This build uses deterministic fixtures by default; live collector validation requires network access.
