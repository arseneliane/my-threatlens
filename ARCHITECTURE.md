# Architecture

FastAPI owns HTTP routes, the shared demonstration login, and background jobs; Jinja2 renders a no-build shell; vanilla JavaScript manages selectors, polling, filters, review state, and imports. SQLAlchemy 2 maps the shared user, hashed sessions, browser-owned setups, scans, findings, source statuses, chats, and audit events to SQLite (or a PostgreSQL URL). Services isolate authentication, matching, enrichment, collection, import, export, and chat behavior. The shared password uses salted PBKDF2-SHA256, browser cookies hold opaque session tokens and workspace identifiers, and the database stores only session hashes. SQLite enables WAL, foreign keys, and a busy timeout.
