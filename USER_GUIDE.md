# User Guide

Choose values in each selector, use Expand All or Collapse All as needed, and save the active setup. Scan Now returns immediately and displays progress. Use table filters without rescanning. Open Review to inspect a threat and ask grounded questions. Use a row's Email button for one threat, select several checkboxes and choose Email selected, or choose Email all found for the complete filtered result set. The email form offers editable subject and message options. Export Excel downloads exactly the currently filtered result set.
