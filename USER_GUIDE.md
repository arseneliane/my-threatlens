# User Guide

Log in with the shared demonstration username `cyber expert` and the password provided privately by the site owner. Each browser has an independent workspace and can create multiple setups. Choose technologies, keywords, sources, and a date range, then select Scan Now. If you change the scope, select Scan Now again to replace the previous results with a fresh search. Values typed under Your additions become removable chips. Scan for Zero Days uses its own separate focused-results section. Use table filters without rescanning. Open Review to inspect a threat and ask grounded questions. Use a row's Email button for one threat, select several checkboxes and choose Email selected, or choose Email all found for the complete filtered result set. Export Excel downloads exactly the currently filtered result set. Use Log out at the bottom of the menu when finished.
