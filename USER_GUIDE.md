# User Guide

Choose values in each selector; technology, keyword, source, custom-entry, and date changes save automatically. Values typed under Your additions become removable chips. Scan Now uses the normal findings table, while Scan for Zero Days uses its own separate focused-results section. Both scans wait for the latest automatic save before starting. Use table filters without rescanning. Open Review to inspect a threat and ask grounded questions. Use a row's Email button for one threat, select several checkboxes and choose Email selected, or choose Email all found for the complete filtered result set. The email form offers editable subject and message options. Export Excel downloads exactly the currently filtered result set.
